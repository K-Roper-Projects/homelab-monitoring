# HomeLab Monitoring

Docker-based monitoring stack using Prometheus, Grafana, Node Exporter and Blackbox Exporter.

## Dashboards

- VM Infrastructure Dashboard using Node Exporter
- Network Health Dashboard using Blackbox Exporter

## Metrics

- VM CPU, RAM, disk and network usage
- Router reachability
- Internet reachability
- Router latency
- Internet latency
- 24-hour uptime percentage

## Stack

- Ubuntu Desktop VM
- Docker Compose
- Prometheus
- Grafana
- Node Exporter
- Blackbox Exporter
